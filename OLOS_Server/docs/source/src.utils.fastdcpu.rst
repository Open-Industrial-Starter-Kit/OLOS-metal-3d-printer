src.utils.fastdcpu package
===========================

This package provides the integration of `FastSD CPU <https://github.com/rupeshs/fastsdcpu>`_, a CPU-based image generation engine used for AI-driven image synthesis on laser cutter machines. 

It allows image generation without the need for a GPU, making it suitable for systems with limited hardware resources.

All required AI models for generation should be add into the ``AI_Models`` directory at the root of the main project.
