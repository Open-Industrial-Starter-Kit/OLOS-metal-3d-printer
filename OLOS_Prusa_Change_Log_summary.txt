OLOS Prusa Slicer Change Log Summary
====================================

Overall Summary
---------------
- Reworked the Prusa path into an OLOS/VisiCut-style metal printing workflow.
- Generated vector contour and hatch G-code from Prusa SL1 slice masks.
- Kept the proven physical hatch/contour spacing fixed at 0.2 mm.
- Added multi-line contours and multi-line hatch bundles for LPBF-style scans.
- Added Prusa-specific controls for infill angle, hatch rotation per layer, contour/infill overlap, scan-order optimization, contour line count, and infill lines per hatch.
- Added per-zone exposure for first and intermediate layers, with the remaining layers using the main contour/infill settings.
- Added OLSK machine routine handling, including no-routine first layers and bed offsets.
- Made estimated print time include actual G-code motion time, including recoater/routine moves.
- Improved preview support for VisiCut-style G-code, with blue contour walls and red infill lines.
- Fixed several Prusa preview/G-code issues around layer count, routine Z interpretation, infill clipping, contour visibility, small model clipping, and stale preview updates.
- Fixed Prusa output centering so generated G-code is placed on the 96 mm circular bed center at X48/Y48 instead of starting near X0/Y0.
- Added machine coordinate overlays for checking origin, bed center, scale, and laser/toolpath position.

Latest LPBF Additions
---------------------
- Hatch Rotation per Layer:
  Adds the configured rotation to the infill angle on each layer. Default is 67 degrees.
- Contour/Infill Overlap:
  Lets infill overlap the innermost contour, or use negative values to create a contour-to-infill gap. Default is 15%.
- Infill Hatch Spacing:
  Controls spacing between hatch bundles so infill density and heat input can be tuned without changing the fixed 0.2 mm line spacing inside each bundle. Default is 1 mm.
- Optimize Hatch Scan Order:
  Alternates hatch direction in a simple serpentine pattern to reduce repeated same-direction scanning.
- Contour Line Count Limit:
  Increased Prusa contour line count support to 25, allowing about 5 mm wall thickness at 0.2 mm spacing.
- Reservoir Lift per Layer:
  Adds a Prusa machine-routine setting for reservoir movement per layer. Default is 0.3 mm and is emitted as the current negative A-axis move.
- Unit Fix:
  Corrected Prusa Contour/Wall Speed display from mm to mm/min.
- Bed-Centered Output:
  Centers Prusa-generated contour/infill geometry on the 96 mm circular bed. Verified benchy_fixed_center.nc has 0 exposure moves outside the bed and about 19 mm radial safety margin.
- Coordinate Scale and Overlay:
  Adds a Slice Preview "Machine coordinates" toggle and a View > Coordinate Scale toggle for checking X0/Y0, X48/Y48 bed center, X/Y scale ticks, and laser/toolpath position.

Validation Summary
------------------
- Backend Python compile checks passed.
- Frontend yarn lint passed.
- Generated G-code was inspected for layer counts, S power values, feedrate formatting, contour/infill separation, routine behavior, and VisiCut-style structure.
- Jobs saved from the 3D slicer now retain an internal transformed model and complete slicing settings. Jobs Manager includes "Open in Slicer" to restore them, while preview/execution and normal downloads continue using only the `.nc` G-code file.
- Added Prusa Lines/Grid infill selection. Grid adds a perpendicular hatch
  direction, switches the laser off across existing hatch lines to prevent
  powered overlap, and provides independent grid-spacing and crossing-clearance
  controls. Clearance follows the absolute contour/infill overlap percentage
  by default, with a toggle for a custom millimetre value.
- Fixed saved slicer projects failing to retain their model/settings when
  reactive Pinia settings could not be cloned.
- Added a Prusa print-height limiter with a vertical slider and millimetre
  input. It clips the preview and stops G-code at the selected complete layer
  without Z-scaling or deforming the model. Saved jobs remember the cutoff.
- The cutoff guide is bed-sized, and releasing the slider automatically
  regenerates G-code, estimated time, and slice-preview data.
- Fixed Prusa engraving mode and added calculated laser-off gantry lead-in and
  lead-out moves using d=(F/60)^2/(2a). Engraving uses single contour/hatch
  tracks, zone-specific feedrates, a configurable XY acceleration, and
  bed-validated compensation travel.
